# Seguimiento de Paradigmas de Programación

Sistema de control de gastos personales implementado mediante diferentes paradigmas de programación, aplicando trabajo colaborativo con Git y GitHub.

## Objetivo

Estudiar y comparar diferentes paradigmas de programación mediante un sistema de gestión de gastos personales.

## Funcionalidades

- Registrar gastos.
- Consultar los gastos registrados.
- Calcular el total acumulado.
- Identificar el gasto de mayor valor.
- Filtrar gastos por monto.
- Buscar gastos por concepto.

## Estructura del proyecto

- `paradigma-estructurado/`: implementación del paradigma estructurado.
- `test/`: archivos de pruebas del proyecto.
- `out/`: archivos generados durante la compilación.

## Tecnologías

- Java
- Git
- GitHub

## Control de versiones

El proyecto utiliza ramas y commits para organizar el desarrollo y registrar los cambios realizados.
